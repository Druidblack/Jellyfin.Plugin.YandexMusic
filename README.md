<div align=center>
<h1>Jellyfin.Plugin.YandexMusic</h1>
  
Метаданные и изображения для исполнителей и альбомов из Яндекс Музыки.

![logo](https://github.com/Druidblack/Jellyfin.Plugin.YandexMusic/blob/main/images/yandexmusic.jpg)

</div>

## Установка

Добавить адрес `` https://raw.githubusercontent.com/Druidblack/Jellyfin.Plugin.YandexMusic/main/manifest.json `` в репозитории плагинов.

Поддерживает:

* Поддерживается автоматическое и ручное сопоставление.
* Изображение и метаданные для альбомов
* Изображения (в том числе и для задников) и метаданные для исполнителей.
